# Artículo 307
Remisión de actuaciones. Las copias y fotocopias de las actuaciones serán remitidas al Ministerio Público en un plazo de tres días, sin perjuicio de lo previsto para el caso de aprehensión de personas.
El original de las actuaciones y las cosas secuestradas, salvo que el Ministerio Público las requiera para diligencias específicas y temporales, siempre quedarán en el Juzgado.

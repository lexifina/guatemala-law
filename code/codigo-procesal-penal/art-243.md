# Artículo 243
Traductores e intérpretes. Si fuere necesaria una traducción o una interpretación, el juez o el Ministerio Público, durante la investigación preliminar, seleccionará y determinará el número de los que han de llevar a cabo la operación. Las partes estarán facultadas para concurrir al acto en compañía de un consultor técnico que los asesore y para formular las objeciones que merezca la traducción o interpretación oficial.

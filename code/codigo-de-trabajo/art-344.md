# Artículo 344
Si no hubiere avenimiento entre las partes, el juez recibirá inmediatamente las pruebas ofrecidas. Toda prueba que no hubiere sido propuesta concretamente en la demanda o que no se aduzca igualmente en la contestación, en la reconvención, así como la impertinente o contra derecho, será rechazada de plano.
Dentro de las veinticuatro horas siguientes a la audiencia, el actor puede ofrecer las pruebas pertinentes para contradecir las excepciones del demandado, si no lo hubiere hecho antes.
En el caso de excepciones interpuestas contra la reconvención, se observará lo dispuesto en el párrafo anterior.

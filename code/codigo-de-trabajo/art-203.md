# Artículo 203
Todos los trabajadores que se ocupen en el manipuleo, fabricación o expendio de productos alimenticios para el consumo público, deben proveerse cada mes de un certificado médico que acredite que no padecen de enfermedades infecto - contagiosas o capaces de inhabilitarlos para el desempeño de su oficio. A este certificado médico es aplicable lo dispuesto en el artículo 163.

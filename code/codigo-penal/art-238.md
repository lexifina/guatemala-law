# Artículo 238
Artículo 238. (Suposición de parto). La mujer que fingiere parto o embarazo para obtener para sí o para el supuesto hijo, derechos que no le correspondan. será sancionada con prisión de uno a tres años. En igual pena incurrirá quien inscribiere o hiciere inscribir en el Registro Civil un nacimiento inexistente. El
médico, la obstetra o comadrona, que coopere a la ejecución de este delito, será sancionado con multa de doscientos a dos mil quetzales.

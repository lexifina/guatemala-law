# Artículo 392
Artículo 392. (Intimidación pública). Quien, para infundir temor público, causar alarma o suscitar tumultos o desordenes, haga estallar petardos o cualquier otro artefacto análogo, o utilice materias explosivas, o amenazare públicamente con un desastre de peligro común, será sancionado con prisión de seis meses a dos años.

# Artículo 398
Artículo 398. (Agrupaciones ilegales de gente armada). Quienes organizaren, constituyeren o dirigieren agrupaciones de gente armada o milicias que no fueren las del Estado, serán sancionados con prisión de tres a diez años. Igual sanción se impondrá a quienes ayuden o colaboren económicamente al mantenimiento de dichas agrupaciones.

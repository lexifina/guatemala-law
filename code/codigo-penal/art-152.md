# Artículo 152
Artículo 152. (Delito por dolo o culpa). Quien, aprovechando su participación en el ejercicio de cualquier deporte, causare, de propósito y con infracción a las reglas o indicaciones correspondientes un resultado dañoso, será responsable del hecho resultante e incurrirá en las sanciones que este Código señala para cada caso. Si el resultado dañoso se causare sin propósito pero con infracción de las reglas o indicaciones respectivas, el responsable será sancionado a título de culpa.

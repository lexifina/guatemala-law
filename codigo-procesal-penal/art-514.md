# Artículo 514
Querellante. Cuando el querellante por adhesión hubiere provocado el procedimiento por medio de una acusación falsa o temeraria, el tribunal podrá imponerle total o parcialmente las costas. En este caso le advertirá previamente sobre esta posibilidad y le otorgará audiencia.
El agraviado que denunció el hecho soportará sus propios gastos, salvo que los deba soportar el condenado o aquel a quien se le impuso una medida de seguridad y corrección.

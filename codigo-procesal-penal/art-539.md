# Artículo 539
Querella. Quien pretenda querellarse y acredite carecer de medios económicos para hacerlo, podrá solicitar el patrocinio de Ministerio público. Este precepto rige especialmente para casos de delito de acción privada.
Admitido el patrocinio, el interesado expedirá el poder especial correspondiente mediante acta ante el Ministerio Público.
